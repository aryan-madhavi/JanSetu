# JanSetu Pitch Deck Outline

## Slide 1: Title
- **JanSetu (जनसेतु)**
- AI for Public Infrastructure and Governance
- Google Build with AI: Code for Communities

## Slide 2: The Problem
- Fragmented citizen feedback.
- Misaligned budget allocation.
- Inability to measure Digital Public Infrastructure (DPI) impact.

## Slide 3: The Solution
- An open-source Digital Public Good.
- Multimodal ingestion: Voice, Text, Images via Messaging apps.
- AI-driven priority scoring and demand clustering.

## Slide 4: How It Works
1. **Ingest**: WhatsApp/Telegram/Web inputs.
2. **Process**: Gemini 2.5 analyzes sentiment, translates, and extracts severity.
3. **Analyze**: Matches demand signals with infrastructure data.
4. **Act**: Dashboard presents ranked projects and policy briefs.

## Slide 5: The Impact
- Transparent Governance.
- Data-driven investments.
- Empowered citizens communicating in their native languages.

## Slide 6: Tech Stack
- Gemini 2.5 Flash / Pro
- Google Cloud TTS, Cloud Run
- FastAPI, React + Vite
